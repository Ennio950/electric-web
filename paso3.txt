Responsabilidades del inspector:

1. Escanear la carpeta:

apps/mobile/app

2. Detectar:

- todas las pantallas .tsx
- rutas de Expo Router
- grupos de rutas (client, builder)
- layouts
- hooks usados
- llamadas a API
- estado global
- dependencias

3. Identificar patrones importantes:

- uso de useState
- uso de useEffect
- uso de fetch
- uso de axios
- imports de api.ts
- imports de Zustand o React Query

4. Detectar arquitectura de navegación:

- Expo Router layouts
- grupos de rutas
- rutas dinámicas [id]

5. Generar estadísticas:

- número de pantallas
- número de layouts
- número de hooks detectados
- número de llamadas a API

6. Detectar posibles problemas:

- pantallas demasiado grandes
- hooks repetidos
- llamadas a API sin capa de servicio
- falta de tipado
- lógica duplicada
